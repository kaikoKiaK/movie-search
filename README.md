# Búsqueda de Películas

Este es un proyecto de búsqueda de películas creado con [Next.js](https://nextjs.org) y bootstrapped con [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Características

- Interfaz de búsqueda de películas
- Índice invertido built from `data/movies.json`
- Enrutamiento client-side y server-side

## Getting Started

Primero, ejecuta el servidor de desarrollo:

```bash
npm run dev
# o
yarn dev
# o
pnpm dev
# o
bun dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

Puedes comenzar a editando la página modificando `app/page.tsx`. La página se actualiza automáticamente a medida que edits el archivo.

Este proyecto usa [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) para optimizar y cargar automáticamente [Geist](https://vercel.com/font), una nueva familia de fuentes para Vercel.
